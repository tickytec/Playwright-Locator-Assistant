Locator

Click "Pick element" to start.

Hover any element and press Alt+Shift+L to capture it without clicking — menus and dropdowns stay open. In picking mode, Tab moves between elements and Enter captures. For a native <select>: open it, close with Esc, then press the shortcut.

Verify

JS and Python syntax, chains, filter(), nth(), frameLocator(), CSS, XPath, text=. Paste several lines to check them all at once.

Record a flow

Clicks, typed values and selections on the page become test steps with the generated locators.

Page object

Use + Page object in the on-page overlay to collect elements. Names are editable.

Recent

Counts are re-checked against the current page every time the popup opens.
